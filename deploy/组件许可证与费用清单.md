# 组件许可证与费用清单

> 一句话结论：**本项目自部署的全部组件都是免费、开源的，可以商用，不需要为它们付费。**
> 但有几个「同名商业版」的坑，新手容易踩，下面用大白话讲清楚。

## 二、3 个「同名商业版」的坑（重点看，别买错）

### 坑 1：Docker Desktop 收费，但我们不用它

- **Docker Desktop**（Windows/Mac 上的那个带界面的软件）：大公司（员工 >250 人或年收入 >1000 万美元）**要付费订阅**。
- **我们用的**：Linux 服务器上的 **Docker Engine + docker compose 命令行**，这是**完全免费**的 Apache 2.0 开源软件。
- 结论：本项目部署在 Linux 服务器，用的是命令行版，**不涉及 Docker Desktop 的收费**。

### 坑 2：Nginx Plus 收费，但我们用开源版

- **Nginx Plus**（Nginx 的商业版）：**付费订阅**，提供额外的高级功能。
- **我们用的**：**Nginx 开源版**，BSD 协议，**免费可商用**。
- 结论：本项目用开源版，**不涉及 Nginx Plus 的收费**。

### 坑 3：Oracle JDK 商业授权收费，但我们用 Temurin

- **Oracle JDK**：从 Java 11 起，Oracle 官方 JDK 商用要 **付费授权**。
- **我们用的**：**Eclipse Temurin（OpenJDK）**，完全免费的开源实现。
- 结论：本项目用 Temurin，**不涉及 Oracle JDK 的收费**。

这些是**业务侧已有的第三方系统**，本项目只是「只读接入」它们的数据，**它们的费用由各自业务方承担，不属于本项目自部署组件**，本项目也不为它们付费：

| 平台 | 说明 |
| --- | --- |
| 新物云、吉客云、米果（sell/tms/wms/supply）、领星 ERP、观远 BI、飞书多维表、FastMoss | 商业 SaaS/内部系统，本项目只读接入 |

## 四、许可证速查（怎么自己验证）

- 每个开源组件的许可证都在它的 GitHub 仓库 `LICENSE` 文件里。
- SeaweedFS 已在线核实：`github.com/seaweedfs/seaweedfs`，许可证 = Apache License 2.0（官方 API 返回 `spdx_id: Apache-2.0`）。
- 判断一个组件「免费/收费」最简单的方法：看它的许可证是不是 OSI 认可的开源协议（Apache-2.0 / MIT / BSD / GPL / PostgreSQL License 等），是就能免费商用；叫「Plus / Enterprise / Desktop / 商业授权」的才可能收费。
